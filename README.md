# AAC-HOCBF — Archived Research Data and Independent Reference Implementation

**Associated manuscript:** *Synchronized Multi-UAV Interception Using Age of Information and Higher-Order Control Barrier Functions*, MDPI *Robotics* (manuscript under revision, November 2026).

> **Important provenance statement:** This repository combines **(A) preserved archival experiment outputs** with **(B) newly authored independent example controller code**. It does **not** contain the original simulator implementation used to produce the paper's reported results. The new reference code cannot reproduce Tables 6–11 from first principles.

## Contents

| Location | Content and provenance |
|---|---|
| `data/` | 141 unchanged original CSV/TXT result files from `TRO_V8_paper_materials.zip` |
| `metadata/` | SHA-256 file manifest and recorded seed IDs |
| `analysis/` | Post hoc checksums, audit, statistical flag inspection and tabular exports (new code) |
| `reports/` | Derived audit and table extracts, not original raw logs |
| `reference_controller/` | **NEW independent numerical illustration** of AoI-conditioned release and softened HOCBF safety filter |
| `reference_runs/` | Output generated by the NEW illustration, separate from original data |
| `tests/` | Unit tests of the newly authored numerical reference implementation |
| `docs/` | Published-scope details, audit exceptions and unresolved reproducibility gaps |
| `overleaf/` | Exact LaTeX Data Availability command and GitHub upload instructions |

## Quick start — archive integrity (standard-library only)

```bash
python3 analysis/verify_checksums.py
python3 analysis/audit_all_seed_metrics.py
python3 analysis/export_archive_tables.py
```

## Quick start — **NEW** illustrative controller (NumPy + SciPy)

```bash
python3 -m pip install -r requirements-reference.txt
python3 -m unittest discover -s tests -v
python3 -m reference_controller.demo --output reference_runs --duration 12
```

Optional backend: install `cvxpy` and `ecos`, then select `--backend cvxpy_ecos`. The default SciPy SLSQP reference solver is **not** the paper's historical CVXPY/ECOS software stack. The demonstration models sampled 2-D point agents, not rigid-body quadrotors. It does not guarantee sampled or continuous-time collision avoidance.

## Results audit — unresolved findings

**DO NOT publish derived checks as a correction to the paper until validated**. Stored synchronization flags do not always agree with the manuscript's stated `ATD <= 0.5 s` rule. In the temporal benchmark, the recovered data flags report AAC 100/100, ATD-based checks give 96/100, and the manuscript reports 95/100. In the five-UAV *no synchronized phase* ablation, original flags give 56/100 but direct ATD checks give 24/100. These issues are fully documented in [`docs/AUDIT_FINDINGS.md`](docs/AUDIT_FINDINGS.md) and `reports/`. Only four distinct preliminary rigid-body trial seed IDs were identified, while the paper refers to six attempts.

The raw `data/` files have not been changed. The original archive contains 301 CSV and 13 TXT files, no historical controller scripts. This repository selects 141 relevant originals and records their paths and hashes.
